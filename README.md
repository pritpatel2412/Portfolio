# Prit Patel | Software Developer Portfolio

Welcome to my personal developer portfolio — a fast, minimal, and highly interactive showcase of my professional experience, technical skills, and software projects. 

This portfolio was designed with a focus on modern web aesthetics, featuring a dark-mode first design, 3D interactive components, and smooth scroll-triggered animations.

---

## 🌟 Key Sections

* **Projects Gallery**: A showcase of my completed and ongoing applications, displayed as interactive 3D tilt-cards with detailed technology badges.
* **Experience Timeline**: A scroll-animated timeline detailing my professional journey, internships, and roles.
* **Project Ideas Lab**: A dynamic gallery of my upcoming software concepts and SaaS ideas. It includes direct integration for visitors to request detailed PRDs (Product Requirements Documents) via email, WhatsApp, or LinkedIn.
* **Interactive Skills**: A comprehensive overview of my frontend, backend, and AI-related technical competencies.

---

## 🛠 Technology Stack

This application is built using modern, industry-standard web technologies to ensure optimal performance and a premium user experience:

### Core Architecture
* **React 19** — Component-based UI architecture
* **Vite** — Lightning-fast build tool and development server
* **React Router Dom** — Seamless client-side routing

### Styling & UI
* **Tailwind CSS v4** — Utility-first styling framework for rapid, responsive design
* **Aceternity UI** — Premium, interactive UI components (e.g., 3D Cards, Hover Border Gradients)
* **Framer Motion** — Complex, physics-based UI animations and scroll transitions
* **GSAP** — High-performance scroll-triggered animations
* **React Icons** — Scalable vector icons for social and contact links

### Utilities
* **EmailJS** — Serverless contact form integration
* **Lenis** — Smooth, momentum-based scrolling experience
* **ESLint & Prettier** — Strict code quality and formatting consistency

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/pritpatel2412/Portfolio.git
cd Portfolio
```

2. **Install dependencies**
```bash
npm install
```

3. **Configure Environment Variables**
If you wish to test the contact form, ensure you have set up an account with EmailJS and replaced the placeholder keys in `src/components/Contact.jsx` with your own `Public Key`, `Service ID`, and `Template ID`.

4. **Start the development server**
```bash
npm run dev
```

The application will be running at `http://localhost:5173`.
