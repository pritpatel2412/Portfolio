# Prit Patel | Developer Portfolio

Welcome to my personal portfolio built with **React and Vite** — a fast, minimal, and elegant showcase of my professional skills and projects.

---

## Technology Stack

* **React** — Component-based UI
* **Vite** — Lightning-fast frontend tooling
* **Tailwind CSS** — Utility-first styling framework
* **EmailJS** — Contact form integration
* **GSAP** — Scroll-triggered animations and UI transitions
* **Lenis** — Smooth scrolling experience
* **ESLint & Prettier** — Code quality and consistency

---

## Features

* Fast load times optimized with Vite
* Fully responsive and mobile-friendly design
* Functional contact form with Gmail-only validation
* Clean animations and smooth scroll effects using GSAP and Lenis
* Polished, user-friendly interface

---

## Getting Started

To run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/pritpatel2412/Portfolio.git

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```
